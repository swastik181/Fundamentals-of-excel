A collection of Excel assignments covering fundamental to intermediate spreadsheet skills, including data input and formatting, cell references, Paste Special, Excel Tables, sorting and filtering, Data Validation, Named Ranges, and error handling.

## 📁 Repository Structure

### 📊 Assignment 1: Excel Fundamentals

This assignment focuses on Excel basics and cell references.

**Topics covered:**

* Data input and formatting
* Relative cell references
* Absolute cell references
* Mixed cell references
* Creating and managing worksheets
* Renaming and rearranging sheets
* Formatting worksheet tabs
* Creating a summary sheet
* Using formulas with relative and absolute references
* Creating a multiplication table using mixed references

**Key Excel concepts:**

* Relative Reference: `B2`
* Absolute Reference: `$C$2`
* Mixed Reference: `$A2` / `A$2`
